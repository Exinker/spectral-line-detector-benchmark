# AGENTS

## Context
Проект посвящен моделированию и исследованию способов обнаружения спектральных линий в атомно-эмиссионных спектрах, регистрируемых линейным детектором.

Задача обнаружения актуальна при низкой интенсивности линии. Таким образом:
- амплитуда линии сравнима с шумом чтения;
- шум гомоскедастичный - шум в зарегистрирвоанном спектре близок к шуму чтения детектора.

## Notes
При обсуждении, реализации и сравнении способов обнаружения:
- использовать `notebook.ipynb` как основной пример экспериментального пайплайна;
- ориентироваться в первую очередь на линии с низкой интенсивностью (сравнимой с шумом чтения);
